# Portfolio migration

The original Gig Work Hub application is preserved under archive/gig-work-hub from the commit before the portfolio styles were added. Its original index, manifest, README, icons and application files are retained. This is a reference snapshot, not a supported deployed app. Existing Git history remains intact.

The portfolio has no database dependency. The former service-worker URL serves a retirement worker that removes only gig-work-hub-shell-* caches and unregisters itself. Keep this file reachable for returning visitors.

The redesigned portfolio uses CSS motion only when reduced motion is not requested. Case study details remain native disclosure controls. No fabricated client results, testimonials, uptime or performance claims were added.
